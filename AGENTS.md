# Agent Guidelines for Note Taker

## Commands
**Client:** `cd client && npm run build/dev/start/lint`  
**Server:** `go build -o server`, `./server`, `gofmt -w .`  
**Test:** No test framework configured

## Code Style
**TypeScript:** Strict mode, ES2017, `@/` imports, PascalCase components, camelCase vars, no semicolons, 2-space indent, async/await, shadcn/Tailwind  
**Go:** gofmt, PascalCase exports, camelCase private, grouped imports, immediate error checks, JSON responses
